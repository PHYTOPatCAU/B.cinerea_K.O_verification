# B.cinerea_K.O_verification
Scripts use for verifying Bc mutants:  Multi-knockout of 29 phytotoxic proteins and metabolites does not completely abolish virulence of the necrotrophic fungus Botrytis cinerea.


Authors:
Nassim Safari, Patrick Pattar, Marat Magomedov, Andrea Tobian Herreño, Shekhar Chule, Alejandra Vielba Fernandez, Luoyu Wu, Frederik Sommer, David Scheuring, Michael Schroda, Remco Stam, Matthias Hahn


This repository contains all scripts used to verify the knock-out mutants. The scripts are written in shell, python and R.
